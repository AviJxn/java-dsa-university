# Recursion Practice Assignment (Java)

Solutions for all 26 questions in the Recursion Practice Assignment.

## How to compile and run

Open a terminal in this folder, then compile and run one file at a time:

```bash
javac Q01_PrintNumbers1ToN.java
java Q01_PrintNumbers1ToN
```

Replace the filename and class name with the question you want to run. Each solution reads input from standard input and prints only the requested output.

## Notes
- Each question is in a separate Java file.
- Every solution uses recursion for the core task.
- Q26 returns the first occurrence of the target in a sorted array.
